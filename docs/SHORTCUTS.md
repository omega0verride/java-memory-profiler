# UI Shortcuts & Tips

Shortcuts and tips displayed in the footer bar of the web UI.
When adding new interactions, add a corresponding entry here **and** in the
`<div class="footer-tips">` section of `src/main/resources/viewer.html`.

Keep entries short — they must fit in a single footer row.

## Current shortcuts

| Input | Action |
|---|---|
| `Scroll` | Zoom time axis |
| `Shift+Scroll` | Zoom memory axis |
| `Drag` | Pan the chart |
| `Click` | Select a data point |
| `Right-click` | Open context menu |
| `Esc` | Deselect / close menu |
| `Ctrl+Click` | Set auto-GC threshold line at cursor height |
